**shortcut** — key that opens the note input in the reviewer (question and answer side). Enter saves, Esc cancels.

**fields** — note type name → the field quick notes are appended to. Note types not listed here take no notes. The field must already exist in the note type (adding one forces a full sync, so the add-on never does it) and is best left off the card templates.

**prefix** — put in front of every note. Placeholders: `{card_type}` (e.g. Listening), `{deck}`, `{date}` (YYYY-MM-DD). `""` for none.

Each note becomes one line in the field. Notes already in the field are shown in the input window once the answer side is showing.
